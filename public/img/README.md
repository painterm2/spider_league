# League imagery

Drop a file named **`scared.jpg`** in this folder and it becomes the
correspondent's live reaction photo — it pops up on the verdict screen and
gets stamped onto the share card whenever a spider is rated extra scary
(Power ≥ 80, or venom flagged as medically significant).

A square-ish photo of someone looking absolutely horrified works best.
No file? The feature quietly stays hidden.
